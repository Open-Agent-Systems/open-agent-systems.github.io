Our aim is practical: help developers spend less time rebuilding foundations and connecting incompatible tools, and more time making useful software.

What we’re working toward

AI development reaches beyond the model. Tools need to work together, execution needs to be manageable, and developers need to understand what their systems are doing. These are the problems we want to work on.

Development
Bring AI into coding, testing, delivery, and collaboration, with attention to the everyday developer experience.
Agents
Make skills, tools, and workflows reusable, so applications can be assembled around real needs.
Operations
Improve execution environments, deployment, resource management, and observability for AI workloads.
Integration
Help independent tools and projects work together without repeated, one-off integration work.

Where we want to go

We expect the work to move from individual tools toward connected systems. Each step should build on working software and lessons from its users.

How we approach the work

  • Keep the boundaries clearPrefer small, composable capabilities with understandable interfaces.
  • Make the work usableDocumentation, examples, and maintainability matter alongside implementation.
  • Show what worksBe clear about what is available, what has been verified, and what is still being explored.

Participate
