Open Agent Systems（OAS）是一个开源组织，关注 AI 辅助研发、智能体，以及支撑它们运行的基础系统。

我们希望开发者少花一些时间重复建设基础功能、适配彼此不兼容的工具，把更多精力放在真正要解决的问题上。

访问 GitHub 组织 ↗建议与反馈 ↗

我们关注的问题

AI 开发不止于模型调用。工具之间需要协作，执行过程需要管理，开发者也需要知道系统正在做什么。这些具体的工程问题，是我们希望持续投入的方向。

开发
让 AI 更好地融入编码、测试、交付与协作，改善日常研发体验。
智能体
让技能、工具和工作流能够复用，围绕实际需求组合应用。
运行
完善执行环境、部署、资源管理和可观测性，让 AI 工作负载更容易运维。
集成
帮助独立工具和项目协作，减少一次又一次的单独适配。

未来往哪里走

我们希望从解决具体问题的工具开始，逐步走向能够相互协作的系统。每一步都应建立在可用的软件和真实的使用反馈之上。

我们怎样做事

  • 边界清楚优先建设职责明确、接口易懂、能够组合的能力。
  • 重视使用除了实现功能，也做好文档、示例和后续维护。
  • 如实说明区分已经可用、已经验证和仍在探索的内容。

参与共建

如果你有使用场景、遇到了集成问题，或者对生态建设有想法，欢迎告诉我们：你想完成什么、被什么阻碍，以及已经尝试过哪些方法。

组织层面的建议可以提交到社区仓库的 Issues。具体项目发布后，相关问题与代码贡献会在各自仓库中处理。
